用春秋的文笔风格讲现代道理。输入一个问题，大儒以春秋故事为你辩经。

## 功能

用户输入一个问题或观点，插件调用 LLM 分两步处理：

1. **分析** — 判断问题适合哪种辩经模式、输出篇幅和语体（白话/文言）
2. **生成** — 将分析结果注入系统提示词，生成符合模式风格的回答

## 命令

| 命令 | 功能 |
|------|------|
| `/大儒帮我辩经 <问题>` | 自动判断模式、长度和语体 |
| `/大儒用文言帮我辩经 <问题>` | 强制以春秋文言输出 |
| `/相劝 <问题>` | 温和相劝 — 顾全情分，徐徐说理 |
| `/大儒 <问题>` | 大儒辩经 — 旁征博引，据理力争 |
| `/圆场 <问题>` | 强行圆场 — 另辟名分，判为君子 |
| `/察小 <问题>` | 痛心疾首 — 小事不察，礼将无存 |

## 四种模式

### 1. 温和相劝
先体谅，再举例劝说，不盛气凌人。适合劝人、安慰、表达不同意见。语气像师长与后辈谈心，恳切而不居高临下。参考《论语》式循循善诱和《出师表》式恳切劝谏。

### 2. 大儒辩经
建立貌似严谨的论证，加入反例或反问。适合反驳、评论、吐槽、讲道理。气势磅礴，逻辑严密。参考《孟子》式比喻论证。

### 3. 强行圆场
为行为另立名分，找出勉强成立的礼法解释。适合洗白、找借口、幽默解释、给台阶下。风格机敏从容，结论出人意料。

### 4. 痛心疾首
把寻常小事提升到秩序与礼法的高度。适合谴责、感叹、表达失望。强调小事不察则礼将无存的道理。参考《礼记》中对礼制的敬重与守护。

## 两种语体

### 白话（默认）
现代白话译文腔，句子像古装影视台词的白话译文，让普通人一遍读懂。适量点缀古词，不堆砌文言，不伪引用经典。

### 文言
以春秋时期文言文写作，模仿《左传》《国语》《论语》《孟子》之文法辞气。使用生僻字与古义，文辞古奥难解

## 篇幅控制

| 篇幅 | 字数 | 说明 |
|------|------|------|
| 小礼 | 70–130 字 | 精炼短评，一个比喻，不展开旧事 |
| 成礼 | 150–260 字 | 完整起承转合，默认长度 |
| 大礼 | 280–450 字 | 层层设喻，推进结论 |

篇幅由 LLM 根据问题复杂度自动判断。

## 工作流

```
用户输入问题
    │
    ▼
[第一步] LLM 分析问题 → 输出 JSON {mode, length, style}
    │
    ▼
[第二步] 将 JSON 注入 system prompt → LLM 生成最终回答
    │
    ▼
输出纯文本回答
```
